- 增加跨平台桌面契约测试、Windows/macOS counter fixture、Windows worker/后代进程取消及 owner 强杀测试；CI 接入 Windows/Linux GUI fixture。同步 README、架构、质量、设计、计划与复现说明。macOS GUI 等待辅助功能/录屏授权，未伪称通过；Cherry、Code Mode、submodule 与 npm 发布仍未修改。
