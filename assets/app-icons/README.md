# App icons

`cherry-computer-use-1024.png` is copied unchanged from Cherry Studio's `build/icons/1024x1024.png` (CherryHQ/cherry-studio), for the Cherry Computer Use app and plugin. The original `open-computer-use-1024.png` remains as an upstream asset and is no longer used by the product build.

The app iconset is generated by `scripts/build-apple-iconset.sh`; release/dev names and bundle identities are documented in `docs/releases/RELEASE_GUIDE.md`.
